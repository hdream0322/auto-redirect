# Auto Redirect

정해 둔 주소에 접속하면 원하는 주소로 대신 열어 주는 Chrome 확장 프로그램입니다.

- 공식 문서를 항상 **한국어 페이지**로 보고 싶을 때
- 옛 주소(사내 위키, 이전 도메인 등)를 **새 주소로 자동 전환**하고 싶을 때
- 특정 페이지를 늘 **다른 페이지로 바꿔서** 열고 싶을 때

리다이렉트는 페이지가 뜨기 전에 일어나므로 원본 페이지가 잠깐 깜빡이지 않습니다.

---

## 설치

> 아직 Chrome 웹 스토어에 올라가 있지 않아, **개발자 모드로 직접 불러오는 방식**만 지원합니다.
> (Chrome 정책상 스토어를 거치지 않은 확장 프로그램은 개발자 모드에서만 동작합니다.)

### 1. 파일 내려받기

- **[Releases](https://github.com/hdream0322/auto-redirect/releases)** 에서 최신 `auto-redirect-vX.Y.Z.zip` 을 받아 압축을 풉니다.
- 또는 이 저장소를 통째로 `git clone` / ZIP 다운로드 합니다.

### 2. Chrome 에 불러오기

1. 주소창에 `chrome://extensions` 입력 후 이동
2. 오른쪽 위 **개발자 모드** 를 켬
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 1번에서 준비한 폴더(`manifest.json` 이 들어 있는 폴더) 선택
4. 툴바에 아이콘이 생깁니다. 자주 쓴다면 퍼즐 조각 아이콘을 눌러 **고정** 해 두세요.

업데이트할 때는 새 버전 파일로 폴더 내용을 교체한 뒤 `chrome://extensions` 에서 새로고침(↻) 을 누르면 됩니다.

## 사용법

### 툴바 아이콘 — 빠른 켜기/끄기

아이콘을 누르면 작은 팝업이 열립니다.

| 요소 | 설명 |
|---|---|
| **on/off 스위치** | 확장 프로그램 전체를 껐다 켭니다. 끄면 규칙은 그대로 남고 리다이렉트만 잠시 멈춥니다. |
| **규칙 설정 열기** | 규칙을 추가·편집하는 설정 페이지를 새 탭으로 엽니다. |

### 설정 페이지 — 규칙 관리

각 규칙은 **원본 주소 → 대상 주소 + 매칭 방식**으로 이루어집니다. **변경사항 저장** 을 누르면 즉시 적용됩니다.

#### 매칭 방식 4가지

| 방식 | 언제 쓰나 | 예시 |
|---|---|---|
| **도메인 전체** (추천) | **사이트 자체**를 다른 사이트로 바꿀 때. `www.` 유무·`http/https`·`m.` 같은 하위 도메인·뒤 경로를 전부 무시하고 도메인만 봄. 원본은 도메인만(`naver.com`) 적어도 됨 | `naver.com` → `https://daum.net` (`www.naver.com`, `m.naver.com`, `naver.com/news` 모두 이동) |
| **정확히 일치** | 주소가 거의 글자 하나까지 똑같은 **딱 한 페이지**만 바꿀 때 (`http/https` 차이와 끝 `/` 유무만 관대) | `.../en/plates` → `.../ko/plates` (그 페이지에서만) |
| **접두사 일치** | 원본 주소로 **시작하는 모든 페이지**를 대상 주소 **한 곳으로** 모을 때 (특정 경로 하위만 골라서 가능) | `https://old.example.com/blog/` 로 시작하는 모든 주소 → 항상 `https://new.example.com/` |
| **부분 치환** | 원본으로 시작할 때 **앞부분만 바꾸고 뒤 경로는 그대로** 유지할 때 (언어 코드 전환에 가장 편함) | `https://wiki.bambulab.com/en/` → `https://wiki.bambulab.com/ko/` 이면 `.../en/무엇이든` 이 `.../ko/무엇이든` 으로 |

> 접두사·부분 치환은 `www.` 유무와 `http/https` 차이를 무시합니다. 대상이 원본과 같은 도메인이면 무한 리다이렉트가 되므로 그 규칙은 자동으로 건너뜁니다.

#### 규칙 예시

| 원본 | 대상 | 방식 | 결과 |
|---|---|---|---|
| `https://wiki.bambulab.com/en/filament-acc/acc/plates` | `https://wiki.bambulab.com/ko/filament-acc/acc/plates` | 정확히 일치 | 해당 페이지 하나만 한국어로 |
| `https://wiki.bambulab.com/en/` | `https://wiki.bambulab.com/ko/` | 부분 치환 | `/en/` 하위 문서를 전부 `/ko/` 로 |

## 알아 두면 좋은 점

- **대상 주소**는 `http://`·`https://` 로 시작하는 전체 주소를 넣어 주세요(생략 시 `https://` 로 간주). 원본은 `도메인 전체` 방식이면 `naver.com` 처럼 도메인만 적어도 됩니다.
- 규칙이 서로 겹치면 **더 구체적인 규칙**(원본 주소가 긴 것 우선, `정확히 일치` > `부분 치환` > `접두사 일치` > `도메인 전체`)이 먼저 적용됩니다.
- 규칙은 `chrome.storage.sync` 에 저장돼 **로그인한 Chrome 사이에 동기화**됩니다. 저장 용량 제한(항목당 약 8KB)이 있어 규칙이 수십 개를 넘으면 저장이 거부될 수 있고, 이때는 상태 메시지로 알려 줍니다.
- 개별 규칙의 **사용** 스위치를 끄면 그 규칙만 잠시 비활성화됩니다.

## 동작 방식

`declarativeNetRequest` 동적 규칙으로 메인 프레임 요청을 리다이렉트합니다.

- 툴바 아이콘 → `popup.html` (on/off 스위치 + 설정 열기)
- 마스터 스위치 상태는 `redirectEnabled` 키에 저장되며, 꺼져 있으면 동적 규칙을 모두 제거합니다.
- 규칙 하나가 잘못돼 일괄 적용이 실패하면, 유효한 규칙만 하나씩 다시 적용합니다.

### 개발 / 테스트 (chrome-devtools MCP)

`.mcp.json` 의 `chrome-devtools` 서버는 확장 프로그램 도구(`--categoryExtensions`)를 쓰기 위해 **파이프 연결**로 동작합니다. 이 모드는 `--autoConnect` / `--browserUrl` 과 함께 쓸 수 없어 MCP 가 전용 Chrome 인스턴스를 직접 띄웁니다(`--isolated`). 설정 변경 후에는 Claude Code 를 재시작해야 반영됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 프로그램 정의 (MV3) |
| `background.js` | 저장된 규칙을 동적 리다이렉트 규칙으로 변환·적용 |
| `popup.html` / `popup.js` | 툴바 아이콘 팝업 (on/off, 설정 열기) |
| `options.html` / `options.js` | 규칙 편집 설정 페이지 |
| `theme.css` | 팝업·설정 페이지 공용 스타일 |
