# Ultimate Auto Redirecter

정해 둔 주소에 접속하면 원하는 주소로 대신 열어 주는 Chrome 확장 프로그램입니다.

- 공식 문서를 항상 **한국어 페이지**로 보고 싶을 때
- 옛 주소(사내 위키, 이전 도메인 등)를 **새 주소로 자동 전환**하고 싶을 때
- 특정 페이지를 늘 **다른 페이지로 바꿔서** 열고 싶을 때
- 업무 시간에만 SNS 를 차단 페이지로 돌리는 등 **조건부 리다이렉트**가 필요할 때

리다이렉트는 페이지가 뜨기 전에 일어나므로 원본 페이지가 잠깐 깜빡이지 않습니다.

---

## 설치

> 아직 Chrome 웹 스토어에 올라가 있지 않아, **개발자 모드로 직접 불러오는 방식**만 지원합니다.
> (Chrome 정책상 스토어를 거치지 않은 확장 프로그램은 개발자 모드에서만 동작합니다.)

### 1. 파일 내려받기

- **[최신 릴리즈 zip 바로 받기](https://github.com/hdream0322/auto-redirect/releases/latest/download/auto-redirect.zip)** — 항상 가장 최근 버전을 내려받습니다. (버전별 파일은 [Releases](https://github.com/hdream0322/auto-redirect/releases/latest) 에서)
- 또는 이 저장소를 통째로 `git clone` / ZIP 다운로드 합니다.

받은 zip 을 원하는 위치에 압축 해제합니다. **이 폴더는 지우거나 옮기지 마세요** — Chrome 이 이 경로로 확장을 인식합니다.

### 2. Chrome 에 불러오기

1. 주소창에 `chrome://extensions` 입력 후 이동
2. 오른쪽 위 **개발자 모드** 를 켬
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 1번에서 준비한 폴더(`manifest.json` 이 들어 있는 폴더) 선택
4. 툴바에 아이콘이 생깁니다. 자주 쓴다면 퍼즐 조각 아이콘을 눌러 **고정** 해 두세요.

### 업데이트

새 버전이 나오면 **기존과 같은 폴더**에 새 zip 내용을 덮어쓴 뒤 `chrome://extensions` 에서 새로고침(↻) 을 누르면 됩니다. 저장해 둔 규칙·그룹·설정은 그대로 유지됩니다.

> 새 폴더에 따로 압축을 풀어 다시 "압축해제된 확장 프로그램을 로드" 하면 **별개의 확장으로 취급되어** 규칙이 딸려오지 않습니다. 이 경우에는 이전 확장에서 **설정 → 내보내기**로 JSON 을 저장한 뒤 새 확장에서 **가져오기** 하세요.

## 사용법

### 툴바 아이콘 — 빠른 조작

아이콘을 누르면 작은 팝업이 열립니다.

| 요소 | 설명 |
|---|---|
| **on/off 스위치** | 확장 프로그램 전체를 껐다 켭니다. 끄면 규칙은 그대로 남고 리다이렉트만 멈춥니다. |
| **잠시 멈추기** | `15분` / `1시간` / `오늘` 중 하나를 누르면 그 시간 동안만 리다이렉트를 쉽니다. 멈춘 상태에서 **같은 버튼을 다시 누르면 해제**되고(눌린 버튼은 강조 표시), 다른 버튼을 누르면 그 시간으로 다시 맞춰집니다. 남은 시간과 **지금 해제** 버튼도 함께 표시됩니다. |
| **＋ 현재 페이지 규칙 만들기** | 지금 보고 있는 탭의 주소로 원본을 자동 채운 미니 폼이 열립니다. 대상 주소만 넣고 저장하면 설정 페이지를 열지 않고 바로 적용됩니다. |
| **규칙 설정 열기** | 규칙을 추가·편집하는 설정 페이지를 새 탭으로 엽니다. |

### 설정 페이지 — 규칙 관리

각 규칙은 **원본 주소 → 대상 주소 + 매칭 방식**으로 이루어집니다. **변경사항 저장** 을 누르면 즉시 적용됩니다.

#### 매칭 방식 5가지

| 방식 | 언제 쓰나 | 예시 |
|---|---|---|
| **도메인 전체** (추천) | **사이트 자체**를 다른 사이트로 바꿀 때. `www.` 유무·`http/https`·`m.` 같은 하위 도메인·뒤 경로를 전부 무시하고 도메인만 봄. 원본은 도메인만(`naver.com`) 적어도 됨 | `naver.com` → `https://daum.net` (`www.naver.com`, `m.naver.com`, `naver.com/news` 모두 이동) |
| **정확히 일치** | 주소가 거의 글자 하나까지 똑같은 **딱 한 페이지**만 바꿀 때 (`http/https` 차이와 끝 `/` 유무만 관대) | `.../en/plates` → `.../ko/plates` (그 페이지에서만) |
| **접두사 일치** | 원본 주소로 **시작하는 모든 페이지**를 대상 주소 **한 곳으로** 모을 때 | `https://old.example.com/blog/` 로 시작하는 모든 주소 → 항상 `https://new.example.com/` |
| **부분 치환** | 원본으로 시작할 때 **앞부분만 바꾸고 뒤 경로는 그대로** 유지할 때 (언어 코드 전환에 가장 편함) | `https://wiki.bambulab.com/en/` → `https://wiki.bambulab.com/ko/` 이면 `.../en/무엇이든` 이 `.../ko/무엇이든` 으로 |
| **정규식** | 위 넷으로 표현되지 않는 복잡한 변환. 원본은 **RE2 정규식**, 대상은 `\1` 같은 역참조를 쓰는 **치환 문자열** | `^https?://(?:www\.)?example\.com/old/(.*)$` → `https://example.com/new/\1` |

> 정확히 일치·접두사·부분 치환은 `www.` 유무와 `http/https` 차이를 무시하고, 포트를 적지 않으면 어떤 포트든 받아들입니다.
>
> **무한 리다이렉트 방어**는 다섯 방식 모두에 걸려 있습니다. 규칙이 만들어 낼 대상 주소를 그 규칙의 매칭 조건에 다시 넣어 보고, 또 걸리면 그 규칙을 적용하지 않습니다(설정 페이지에서도 해당 행이 빨갛게 표시됩니다). 예를 들어 접두사·부분 치환에서 대상이 원본으로 시작하거나, 정규식 치환 결과가 원본 정규식에 다시 맞으면 거부됩니다.

#### 그룹 (폴더)

- **＋ 그룹** 으로 그룹을 만들고, 각 규칙 행의 **그룹** 드롭다운으로 규칙을 옮깁니다.
- 그룹 헤더에서 **이름을 바로 편집**하고, **그룹 스위치**로 그 그룹 규칙을 통째로 껐다 켤 수 있습니다.
- 그룹을 지워도 규칙은 사라지지 않고 **미분류** 로 이동합니다.

#### 검색 · 정렬

- 검색창에 문자열을 넣으면 그룹을 넘나들며 **원본·대상 주소**를 부분 일치로 걸러 냅니다.
- 정렬 드롭다운(`저장 순서` / `원본 주소순` / `최근 추가순` / `매칭 방식순`)은 **화면 표시만** 바꾸며 저장 순서는 그대로입니다.

#### 규칙 펼침 영역 — 예외 · 시간 조건

각 규칙 아래의 **예외 · 시간 조건** 을 펼치면 다음을 지정할 수 있습니다.

| 항목 | 설명 |
|---|---|
| **물음표 뒤 검색어 떼기** | `부분 치환` 방식에서만 나타납니다. 켜면 `?` 뒤 쿼리스트링을 버리고 경로만 이어 붙입니다. |
| **제외 패턴** | 한 줄에 하나씩. 주소에 그 문자열이 들어 있으면 리다이렉트하지 않습니다. `*` 는 아무 글자나 뜻합니다. `/admin` 처럼 경로만 적어도 되고 `naver.com/admin` 처럼 주소째 적어도 됩니다. **제외는 그 규칙 하나에만 적용되며 다른 규칙은 건드리지 않습니다.** |
| **시간 조건** | 요일 체크박스 7개 + 시작/끝 시각. 요일을 하나도 고르지 않으면 매일, 시작·끝이 같거나 비어 있으면 하루 종일 동작합니다. `22:00 ~ 02:00` 처럼 자정을 넘겨도 되며, 이때 요일은 **시작한 날**을 기준으로 봅니다(금요일 `22:00~02:00` 이면 토요일 새벽 1시도 포함). |

#### 가져오기 / 내보내기

- **내보내기** 는 `{ version, rules, groups }` 형태의 JSON 파일을 내려받습니다.
- **가져오기** 로 그 파일을 고르면 **교체**(기존 규칙 삭제 후 적용) 와 **병합**(기존 규칙 뒤에 추가) 중 하나를 고를 수 있습니다. 형식이 맞지 않는 항목은 건너뛰고 개수를 안내합니다. 가져온 뒤 **변경사항 저장** 을 눌러야 실제로 적용됩니다.

#### 규칙 예시

| 원본 | 대상 | 방식 | 결과 |
|---|---|---|---|
| `https://wiki.bambulab.com/en/filament-acc/acc/plates` | `https://wiki.bambulab.com/ko/filament-acc/acc/plates` | 정확히 일치 | 해당 페이지 하나만 한국어로 |
| `https://wiki.bambulab.com/en/` | `https://wiki.bambulab.com/ko/` | 부분 치환 | `/en/` 하위 문서를 전부 `/ko/` 로 |
| `^https?://(?:www\.)?youtube\.com/shorts/(.*)$` | `https://www.youtube.com/watch?v=\1` | 정규식 | Shorts 를 일반 재생 페이지로 |

## 알아 두면 좋은 점

- **대상 주소**는 `http://`·`https://` 로 시작하는 전체 주소를 넣어 주세요(생략 시 `https://` 로 간주). `도메인 전체` 방식의 원본은 `naver.com` 처럼 도메인만 적어도 되고, `정규식` 방식은 URL 검사를 하지 않습니다.
- 규칙이 서로 겹치면 **더 구체적인 규칙**(원본 주소가 긴 것 우선, `정확히 일치` > `정규식` > `부분 치환` > `접두사 일치` > `도메인 전체`)이 먼저 적용됩니다.
- 규칙은 `chrome.storage.sync` 에 저장돼 **로그인한 Chrome 사이에 동기화**됩니다. 항목당 8KB 제한을 피하려고 JSON 을 ASCII 로 이스케이프한 뒤 6000자(=6000바이트) 조각으로 나눠 `redirectRules_0`, `redirectRules_1` … 에 저장합니다. 한글 주소도 바이트 수가 정확히 계산되므로 조각 하나가 8KB 를 넘지 않습니다. 기존 `redirectRules` 단일 키는 첫 실행 때 자동 변환됩니다.
- **동기화가 덜 끝난 상태를 규칙 0개로 오해하지 않습니다.** 조각 개수·전체 길이·규칙 개수를 함께 저장해 두고 셋 중 하나라도 어긋나면 "불러오지 못했다"고 판단해서, 확장 프로그램은 **기존 리다이렉트 규칙을 그대로 유지**하고 설정 페이지는 경고 배너를 띄운 뒤 저장 버튼을 잠급니다. 잠시 뒤 새로고침하면 됩니다.
- 여러 창·기기에서 동시에 편집해도 서로 덮어쓰지 않도록 **`rev` 번호로 낙관적 잠금**을 겁니다. 불러온 뒤 다른 곳에서 먼저 저장이 있었으면 저장이 거부되고, **되돌리기**로 최신 내용을 받아 다시 저장하면 됩니다.
- 개별 규칙의 **사용** 스위치를 끄면 그 규칙만, **그룹 스위치**를 끄면 그 그룹 전체가 잠시 비활성화됩니다.
- 브라우저가 규칙을 거부하거나(주소가 아주 길어 정규식이 2KB 한도를 넘는 경우 등) 동적 규칙 개수 한도를 넘으면, 나머지 규칙은 그대로 두고 팝업·설정 페이지에 안내 배너가 뜹니다.

## 동작 방식

`declarativeNetRequest` 동적 규칙으로 메인 프레임 요청을 리다이렉트합니다.

- 툴바 아이콘 → `popup.html` (on/off, 스누즈, 현재 페이지 규칙 추가, 설정 열기). 현재 탭 주소는 `activeTab` 권한으로 팝업을 연 순간에만 읽습니다.
- 마스터 스위치는 `redirectEnabled`, 스누즈는 `redirectSnooze = {until, spec?}`, 그룹은 `redirectGroups` 키에 저장됩니다. 마스터가 꺼져 있거나 스누즈 중이면 동적 규칙을 모두 제거합니다.
- **우선순위 대역**: 규칙을 `매칭 방식 → 원본 주소 길이 → 저장 순서` 로 정렬한 뒤 규칙마다 10칸짜리 대역을 줍니다. 대역 안에서 `redirect` 는 아래(+0), 그 규칙의 제외(`allow`)는 위(+5)에 놓입니다. 규칙 id 는 `redirect` 가 `1..N`, `allow` 가 별도 대역이라 겹치지 않습니다.
- **제외 패턴이 다른 규칙으로 새지 않는 이유**: DNR 의 `allow` 에는 "이 규칙에만"이라는 개념이 없어서, 우선순위만 조절하면 낮은 우선순위의 다른 규칙까지 함께 막힙니다. 그래서 `allow` 의 조건을 **그 규칙이 건드릴 URL 의 부분집합**이 되도록 만듭니다 — `allow` 의 `regexFilter` = `(그 규칙의 매칭 접두사 정규식) + ".*" + (제외 패턴)`. 다른 규칙이 담당하는 URL 은 애초에 이 정규식에 걸리지 않습니다. 제외 패턴을 절대 주소로 적으면 그 규칙의 접두사만큼 잘라 내 접두사와 겹쳐도 매칭되게 합니다.
  - `도메인 전체` 는 접두사가 호스트에서 끝나 뒤의 `.*` 가 더 긴 호스트까지 삼킬 수 있으므로(`naver.com` 규칙이 `naver.com.evil.com` 까지), 호스트 뒤에 구분자(`/?#`)나 문자열 끝이 오는 갈래와 제외 패턴이 호스트 바로 뒤에 오는 갈래를 `|` 로 묶어 호스트 끝을 앵커합니다.
  - `정확히 일치` 는 대상 URL 이 하나뿐이라 빌드 시점에 판정해 `allow` 규칙을 아예 만들지 않고, 제외에 걸리면 그 규칙만 적용하지 않습니다.
  - `정규식` 이 `$` 로 끝나 **집합이 닫혀 있으면**(예: `…/(foo|bar)$`) `$` 를 떼는 순간 집합이 넓어져 안전한 부분집합을 만들 수 없습니다. 이때는 `allow` 를 만들지 않고 배너로 알려 줍니다(`…/(.*)$` 처럼 끝이 열린 형태는 `$` 를 떼도 집합이 같으므로 그대로 동작합니다).
  - 제외 패턴이 **그 규칙의 접두사 자체**에 걸리면(예: 규칙 `a.com/docs/guide` 에 제외 `/docs`) 매칭되는 모든 주소가 제외 대상이므로 그 규칙을 통째로 끕니다 — 조용히 무의미해지지 않습니다.
- DNR 자체에는 시간 조건이 없어, 시간 조건이 있는 규칙이 하나라도 있으면 `chrome.alarms` 로 **1분마다** 규칙을 다시 계산합니다(없으면 알람을 만들지 않습니다). 스누즈 만료 시각에도 알람이 한 번 울립니다.
- 저장 한 번이 `storage.onChanged` 를 여러 번 부르므로, 규칙 적용은 **100ms 디바운스 + 프라미스 체인 직렬화**로 한 번만, 순서대로 실행합니다.
- 규칙 하나가 잘못돼 일괄 적용이 실패하면 **규칙 단위로** 다시 적용합니다. 이때 `redirect` 가 거부되면 그 규칙의 `allow` 도 넣지 않습니다 — 주인 없는 `allow` 가 남으면 다른 규칙까지 계속 막기 때문입니다. 거부된 규칙은 원본 주소와 함께 배너로 알려 줍니다.

### 테스트

```bash
node --test test/*.mjs
```

`test/chrome-stub.mjs` 가 `chrome.storage` / `chrome.declarativeNetRequest` / `chrome.alarms` 를 메모리로 흉내 내므로 브라우저 없이 돌아갑니다. 청크 저장·무결성·`rev` 잠금·무한 루프 방어(`storage.test.mjs`)와 우선순위·제외 패턴 격리·실패 처리(`background.test.mjs`)를 검사합니다.

> 리다이렉트가 몇 번 일어났는지 세거나 알림을 띄우는 기능은 없습니다. 프로덕션 빌드의 `declarativeNetRequest` 는 매칭 이벤트를 확장 프로그램에 알려 주지 않기 때문입니다.

### 개발 / 테스트 (chrome-devtools MCP)

`.mcp.json` 의 `chrome-devtools` 서버는 확장 프로그램 도구(`--categoryExtensions`)를 쓰기 위해 **파이프 연결**로 동작합니다. 이 모드는 `--autoConnect` / `--browserUrl` 과 함께 쓸 수 없어 MCP 가 전용 Chrome 인스턴스를 직접 띄웁니다(`--isolated`). 설정 변경 후에는 Claude Code 를 재시작해야 반영됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 프로그램 정의 (MV3, `background.type: module`) |
| `storage.js` | 공용 저장소 모듈 — 청크 분할 저장/읽기·무결성 검사·`rev` 잠금, 마이그레이션, 그룹·스누즈, 규칙 유효성/무한루프 판정, URL 유틸 |
| `background.js` | 저장된 규칙을 동적 리다이렉트/allow 규칙으로 변환·적용, 알람 관리 |
| `popup.html` / `popup.js` | 툴바 아이콘 팝업 (on/off, 스누즈, 현재 페이지 규칙 추가, 설정 열기) |
| `options.html` / `options.js` | 규칙 편집 설정 페이지 (그룹·검색·정렬·가져오기/내보내기·예외·시간 조건) |
| `theme.css` | 팝업·설정 페이지 공용 스타일 |
| `test/*.mjs` | `node --test` 회귀 테스트 (브라우저 없이 실행) |
